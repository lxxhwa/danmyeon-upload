개인정보처리방침

시행일: 2026년 10월 28일

단면도감 업로더(이하 "이 도구")는 채널 운영자 한 사람이 자기 계정에 자기 영상을 올리기 위해 만든 도구예요. 다른 사용자를 받지 않아요.

수집하는 정보

운영자가 직접 연결한 유튜브, 인스타그램, 스레드, 틱톡 계정의 접근 토큰과 계정 ID만 사용해요. 다른 사람의 개인정보는 수집하지 않아요.

사용 목적

토큰은 운영자 계정에 영상과 설명 글을 올리고, 올린 게시물의 주소를 확인하는 데만 써요.

보관과 공유

토큰은 GitHub의 암호화된 저장소 비밀값에만 보관하고, 제3자에게 팔거나 넘기지 않아요. 연결을 끊으면 비밀값을 지우고, 각 서비스의 계정 설정에서 언제든 접근 권한을 취소할 수 있어요.

Google 사용자 데이터

이 도구가 YouTube API 서비스로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따라요. 이 도구는 YouTube 서비스 약관과 Google 개인정보처리방침을 따르는 YouTube API 서비스를 사용해요. 접근 권한은 Google 보안 설정 페이지에서 취소할 수 있어요.
