# 단면도감 자동 업로드

저녁 6시(한국 시간)에, 대기 영상이 7편 미만이면 월·수·금, 7편 이상이면 매일 `queue/` 에서 아직 안 올린 편을 하나 꺼내 유튜브 쇼츠, 인스타 릴스, 스레드에 올려요.

- 한 편 = `queue/<번호_이름>/video.mp4` + `upload_copy.md`
- 올린 기록은 `posted.json` 에 남아요. 실패한 곳만 다음 실행 때 다시 시도해요.
- AI 표시: 유튜브는 '변경되거나 합성된 콘텐츠', 인스타는 'AI 정보' 라벨을 켜서 올려요. 스레드는 API에 표시 기능이 없어서 글 끝에 "AI로 만든 영상"이라고 적어요.
- 직접 돌리기: Actions 탭 → 업로드 → Run workflow (올릴 곳과 유튜브 공개 범위를 고를 수 있어요)
