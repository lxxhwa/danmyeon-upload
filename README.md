# 단면도감 자동 업로드

저녁 6시(한국 시간)에, 대기 영상이 7편 미만이면 월·수·금, 7편 이상이면 매일 `queue/` 에서 아직 안 올린 편을 하나 꺼내 유튜브 쇼츠, 인스타 릴스, 스레드에 올려요.

- 한 편 = `queue/<번호_이름>/video.mp4` + `upload_copy.md`
- 올린 기록은 `posted.json` 에 남아요. 실패한 곳만 다음 실행 때 다시 시도해요.
- AI 표시: 유튜브는 '변경되거나 합성된 콘텐츠', 인스타는 'AI 정보' 라벨을 켜서 올려요. 스레드는 API에 표시 기능이 없어서 글 끝에 "AI로 만든 영상"이라고 적어요.
- 직접 돌리기: Actions 탭 → 업로드 → Run workflow (올릴 곳과 유튜브 공개 범위를 고를 수 있어요)

## 유튜브 재생목록

- `playlists.json` 에 채널별 재생목록(제목·설명·넣을 편)을 적어요. `"items": "all"` 은 올라간 편 전부예요.
- 업로드가 끝날 때마다 `playlists.py` 가 돌아서 새 편을 맞는 재생목록 끝에 넣어요. 새 편을 주제 재생목록에도 넣고 싶으면 그 목록의 `items` 에 폴더 이름을 추가하면 돼요(안 적으면 전체 재생목록에만 들어가요).
- 한 번에 맞추기: Actions 탭 → 재생목록 맞추기 → Run workflow

## 유튜브 썸네일

- 편 폴더에 `thumb.jpg`(영상 첫 장면, 훅 문구 화면)가 있으면 업로드하자마자 유튜브 썸네일로 넣어요. 없으면 유튜브가 영상 중간 장면을 골라서 훅 문구가 안 보여요.
- 이미 올라간 편 고치기: Actions 탭 → 유튜브 썸네일 바꾸기 → Run workflow → 편 폴더 이름 입력
